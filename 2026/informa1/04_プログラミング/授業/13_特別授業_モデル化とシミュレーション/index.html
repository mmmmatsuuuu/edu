    第13時（特別授業）：モデル化とシミュレーション

    本時の目標

    「40人で一斉にじゃんけんをしたら、勝負がつくまで何分かかるか？」という問いを、実演とPythonによるシミュレーションで調べる活動を通して、モデル化とシミュレーションの意義（実際には試せないことを試せる・条件を変えて何度でも試せる）を実感する。

    年間計画の単元07「モデル化とシミュレーション」（4時間）は授業時数の都合で実施せず、その内容を本単元の特別授業1時間に圧縮して扱う。

    本時のルール（勝負がつく条件）

    • 全員で一斉にじゃんけんをする
    • 出た手が2種類だけ（例：グーとチョキだけ）になったら「勝負がついた」とする
    • 3種類すべてが出た／全員が同じ手だった場合はあいことしてやり直す
    • 「勝負がつくまでの回数」×「1回あたりの秒数」で、かかる時間を求める

    教師用：参考値（人数ごとの平均回数）

    1回で勝負がつく確率は 3 × (2^n − 2) / 3^n（n：人数）で、平均回数はその逆数になる。

    人数 平均回数 1回5秒の場合 1回10秒の場合
    10 約19回 約1.6分 約3.2分
    12 約43回 約3.6分 約7.2分
    13 約65回 約5.4分 約10.8分
    14 約97回 約8.1分 約16分
    15 約146回 約12分 約24分
    20 約1,108回 約1.5時間 約3時間
    40 約369万回 約213日 約427日
    • 10分以内に収まる人数の限界：1回5秒なら14人、1回10秒なら12人
    • 10人でもばらつきが大きい（シミュレーションでは中央値13回・最大200回超）。実演では、グループ間で回数に差が出るのが普通である

    キーワード

    用語 説明
    モデル 現実の対象や現象から、目的に必要な要素だけを取り出して単純化して表したもの
    モデル化 目的に合わせて要素を取り出し、関係を整理してモデルを作ること
    シミュレーション モデルを使って、現実では試しにくいことを模擬的に試すこと
    モデルの分類 表現形式（物理・図的・数理）、時間経過（動的・静的）、偶然性（確定的・確率的）の観点で分けられる（詳細は動画の構成案を参照）
    確率的モデル 偶然の要素（乱数）を含むモデル。結果が毎回変わるため、何度も試行して傾向を見る
    検証 シミュレーションの結果を現実と比べ、モデルが妥当かを確かめること

    動画の構成案（10分）

    時間 内容
    2分 モデルとは何か・モデル化とシミュレーションの流れ（目的 → モデル化 → シミュレーション → 検証）
    6分 モデルの分類（表現形式・時間経過・偶然性の3つの観点）と、それぞれのシミュレーションの具体例（下表）
    2分 シミュレーションのよさ（実際には試せない・危険・時間や費用がかかることを試せる）と注意点（モデルには仮定があり、結果は前提つき）。本時のじゃんけんがどのモデルにあたるかを予告する

    モデルの分類と具体例

    観点 モデルの種類 特徴 具体例と、どのようにシミュレーションするか
    表現形式 物理モデル 実物を縮小・拡大したり、形を似せたりして作る立体的なモデル 自動車や飛行機の模型を風洞に入れて風を当て、空気抵抗を調べる。建築模型に光を当てて日当たりを確かめる
    表現形式 図的モデル 対象の構成要素や関係を、図で表したモデル 路線図をたどって乗り換えや所要時間を比べる。フローチャートを指でたどって手順に誤りがないか確かめる
    表現形式 数理モデル 対象の性質や関係を、数式や論理式で表したモデル 預金の金額を「元金×(1＋利率)^年数」で表し、年数や利率を変えて表計算やプログラムで計算する
    時間経過 動的モデル 時間の経過によって状態が変化するモデル 人口の推移や感染症の広がりを、「1日（1年）進めて計算する」ことを繰り返して予測する
    時間経過 静的モデル 時間の経過に関係しないモデル 売上を「単価×個数」で表し、単価を変えると売上がどう変わるかを比べる。地図で2地点間の距離を求める
    偶然性 確定的モデル 偶然の要素を含まず、同じ条件なら必ず同じ結果になるモデル ボールの落下を数式で計算する。複利計算と同様に、1回計算すれば結果が決まる
    偶然性 確率的モデル 偶然の要素を含み、同じ条件でも結果が毎回変わるモデル サイコロやレジの待ち行列を、乱数を使って何度も試し、平均やばらつきを見る。本時のじゃんけんはこれにあたる
    • 1つのモデルは3つの観点それぞれで分類できる（例：本時のじゃんけんは「数理モデル（プログラムで表現）」かつ「確率的モデル」）。動画では観点ごとに分けて紹介し、最後に本時の題材がどれにあたるかを示す
    • 本時の演習でとくに重要なのは確率的モデル（何度も試して平均をとる理由）であるため、確定的モデルとの対比を丁寧に扱う

    準備物・教材

    • モデル化とシミュレーションの基本を説明する動画（10分程度。上記の構成案のとおり）
    • ワークシート（予想・実演の記録・シミュレーション結果・振り返りの記入欄）
    • 配布コード2本（下記。Google Colab 等で実行。生徒は数値の書き換えのみ行う）
    • ストップウォッチ（各グループ1つ。生徒の端末でも可）

    配布コード①：1回だけシミュレーションする（3-3で使用）

    import random

n = 10            # じゃんけんする人数（2〜45人）
seconds = 5       # じゃんけん1回にかかる秒数（実演で測った値を入れる）

# 人数の範囲チェック（多すぎるとコンピュータが長時間止まらなくなるため）
if n > 45:
    print("人数は45人までです。45人で実行します")
    n = 45
if n < 2:
    print("人数は2人以上です。2人で実行します")
    n = 2

count = 0
while True:
    count = count + 1
    hands = []
    for i in range(n):
        hands.append(random.choice(["グー", "チョキ", "パー"]))
    if len(set(hands)) == 2:   # 出た手が2種類なら勝負あり
        break
    if count % 1000000 == 0:   # 100万回ごとに途中経過を表示
        print(count, "回目…まだ勝負がつきません")

minutes = count * seconds / 60
print(n, "人で", count, "回目に勝負がつきました")
print("かかった時間：約", round(minutes, 1), "分")
if minutes >= 60 * 24:         # 1日以上かかったときは日数も表示
    print("（日に直すと約", round(minutes / 60 / 24, 1), "日）")
    • 40人も時間の上限を設けずに最後まで実行させる。「実際にやれば半年以上かかることが、プログラムなら数分で終わる」ことを、待ち時間を含めて体感させるのがねらいである
    • 人数は45人までに制限している（それより大きい数を入れると45人に置き換えて実行する）。ふざけて大きな人数を入れ、コンピュータが長時間止まらなくなるのを防ぐためである。1人以下を入れた場合も、勝負がつかず止まらなくなるため2人に置き換える
    • 実行時間の目安：40人の平均（約369万回）で、一般的なPCで約30秒、Google Colab では1〜2分程度。回数は試行ごとに大きくばらつき、平均の2〜3倍（Colabで数分）かかることも1割程度ある。なお45人の平均は約2,800万回（1回5秒で約1,620日）で、Colabでは10分前後かかる見込みのため、40人以外は基本的に試させない
    • 100万回ごとに途中経過が表示されるので、止まっているわけではないことが分かる。待っている間に「この回数を人間がやったら何日か」を計算させてもよい
    • 結果は「分」で表示する（本時の問いが「何分かかるか」のため）。1日以上かかったときだけ、補助として日数も表示する
    • 5分程度たっても終わらない生徒は実行を止めさせ（Colabの停止ボタン）、そこまでの途中経過と、終わった生徒の結果を共有する

    配布コード②：何回も試して平均をとる（3-4で使用）

    import random

n = 10            # じゃんけんする人数（2〜20人。ここを変えて調べる）
seconds = 5       # じゃんけん1回にかかる秒数（実演で測った値を入れる）
trials = 100      # 試行回数（1〜1000回。何回シミュレーションして平均をとるか）

# 範囲チェック（大きすぎるとコンピュータが長時間止まらなくなるため）
if n > 20:
    print("人数は20人までです。20人で実行します")
    n = 20
if n < 2:
    print("人数は2人以上です。2人で実行します")
    n = 2
if trials > 1000:
    print("試行回数は1000回までです。1000回で実行します")
    trials = 1000
if trials < 1:
    trials = 1

total = 0
for t in range(trials):
    count = 0
    while True:
        count = count + 1
        hands = []
        for i in range(n):
            hands.append(random.choice(["グー", "チョキ", "パー"]))
        if len(set(hands)) == 2:
            break
    total = total + count

average = total / trials
print(n, "人の平均回数：", round(average, 1), "回")
print("平均時間：約", round(average * seconds / 60, 1), "分")
    • 平均をとるために何度も繰り返すので、人数は20人まで、試行回数は1000回までに制限している（上限いっぱいの20人×1000回でも数秒〜十数秒で終わる）。3-4で調べる人数の目安は10〜16人程度

    授業展開

    時間 段階 学習活動 指導上の留意点
    3分 導入 本時の問い「40人で一斉にじゃんけんをしたら、勝負がつくまで何分かかる？」を示し、各自の予想をワークシートに書く 予想は直感でよいと伝える。予想と結果のずれが本時の山場になるため、必ず記録させる
    10分 動画視聴 モデル化とシミュレーションの基本（モデルとは何か・モデル化の流れ・モデルの分類と具体例・シミュレーションのよさと注意点）を動画で学ぶ 「目的 → モデル化 → シミュレーション → 検証」の流れを板書に残し、演習でこの流れをたどることを予告する
    2分 演習 3-1：説明 ルール（2種類の手だけが出たら勝負あり）と、記録すること（勝負がつくまでの回数・かかった時間）を確認する 40人を10人×4グループに分ける。記録係とストップウォッチ係を決めさせる
    7分 演習 3-2：10人でやってみよう グループごとに一斉じゃんけんをし、勝負がつくまでの回数とかかった時間を記録する。終わったら「1回あたりの秒数」を計算する 5分で打ち切る（終わらないグループがあっても、それ自体が結果になる）。各グループの回数を板書し、ばらつきがあることに注目させる
    10分 演習 3-3：Pythonでシミュレーション 配布コード①の seconds に実演で測った秒数を入れ、まず n = 10 で何回か実行して実演の結果と比べる（＝検証）。次に n = 40 にして、勝負がつくまで実行する 10人の結果が実演と同じくらいになることを確かめてから40人に進む。40人は1〜数分かかるため、早めに実行を始めさせる。終わった生徒の回数・時間（分）を何人分か板書し、ばらつきを確認したうえで「平均は約369万回、1回5秒なら約213日」と示し、予想とのずれと「現実なら半年以上かかることが数分で終わった」ことを共有する
    10分 演習 3-4：10分以内の限界を調べよう 配布コード②で n を変えながら平均時間を調べ、10分以内に終わる人数の限界を見つける。結果をワークシートの表に記録する 1回だけの試行では結果がぶれることを3-2・3-3で確認したうえで、「何回も試して平均をとる」意味を押さえる。早く終わった生徒には trials を増やすと結果がどう変わるかを試させる
    8分 まとめ 予想と結果のずれを振り返り、シミュレーションの意義（実際にはできないことを試せる・条件を変えて何度でも試せる）を確認する。モデルの仮定と限界にも触れる。ワークシートに「シミュレーションのよさ」と「注意点」を書く 仮定の例：1回の秒数は人数によらず一定としている（実際は人数が増えると延びる）、手は完全にランダムとしている。「モデルは目的に合わせた単純化であり、結果には前提がある」ことを押さえる

    発展（時間に余裕がある場合）：「40人を10分以内に終わらせるには、ルールをどう変えればよいか？」（例：少人数のグループに分けて勝ち抜き戦にする）を考えさせ、シミュレーションで確かめる。

    板書・スライド構成

    1. 問い：40人で一斉にじゃんけんをしたら、勝負がつくまで何分かかる？（予想）
    2. モデル化とシミュレーションの流れ：目的 → モデル化 → シミュレーション → 検証
    3. モデルの分類（表現形式・時間経過・偶然性）と本時の題材の位置づけ（数理モデル・確率的モデル）
    4. ルール：2種類の手だけが出たら勝負あり
    5. 実演の記録（グループごとの回数・時間・1回あたりの秒数）
    6. シミュレーション結果：10人（実演と比べる）→ 40人（生徒の結果を板書／平均約369万回・約213日。プログラムなら数分）
    7. 10分以内の限界人数（試行回数を増やして平均をとる）
    8. まとめ：シミュレーションのよさと注意点（モデルの仮定と限界）

    本時の評価

    本時は成績評価の対象とせず、教師の授業改善のための見取りにとどめる。

    観点 評価方法 内容
