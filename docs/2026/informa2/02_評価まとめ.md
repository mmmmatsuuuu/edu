# 情報Ⅱ 科目評価まとめ（2026年度）

> **前提（重要）**
>
> - 本まとめは **2026年10月3日時点の中間総括**。評価データのある単元（01・02）の `02_評価まとめ.md` を統合したもので、年度の最終評価ではない。
> - 対象は3年11名の**選択科目**。全員を1クラスとみなして分析している。1人で正答率が約9〜10%動くため、数%の差は設問の難しさの差とは言えない。
> - 評価（1〜5）は**授業改善のための到達度の目安**（5：ほぼ全員が到達／4：多くが到達（一部につまずき）／3：おおむね到達（主要部分に課題）／2：到達した生徒が少ない／1：ほとんど到達していない）。学校の評価・評定とは別で、一致させる必要はない。
> - 評価の根拠は**小テストと生徒メモのみ**。年間計画で割合の大きい**演習（提出物・制作物・発表・プロジェクトへの貢献度：60%）と単元テスト（40%）は本データに含まれない**ため、すべて暫定。特に、年間プロジェクト（デジタルスタンプラリー）に関わる成果は未確認。
> - 02（コンテンツ）は第1〜4時（座学）のデータのみ。

## 最終評価まとめ

> ※中間総括（2026年10月3日時点）。2単元・暫定評価に基づく。

### 観点別の全体像

- **知識・技能**：情報社会・メディア・UI・発信の概念と用語は、ほとんどの生徒が到達（5 → 4）。法令・制度の細部（条番号、各国法制の違い）や、形式の使い分け（背景透過に適した形式：70%）など、**細部や応用的な判断**でやや落ちる。
- **思考・判断・表現**：概念を自分の言葉で説明する力は両単元で高い（DXとデジタル化の違い、デジタルデバイドが構造的問題である理由、コントロールによるオウンド/アーンドの違いなど）。一方、**具体例や両面（便利さと代償）まで書く記述**、**手順・サイクルの順序づけ**は単元をまたいで弱い。評価方法の中心（開発計画書・演習発表・制作物）は未確認のため、4 → 3。
- **主体的に学習に取り組む態度**：AI・DX・倫理・プライバシー、学校の広報への応用など、**技術と社会の接点への関心が強い**（01の評価4）。グループでの取り組みは本データでは見えず、02は3とした。

## 気づき・課題

### 年度を通して見えてきた共通の傾向

1. **概念・用語の定着は非常に高く、小テストの識別力が低い**：01・02とも、選択式の多くが80〜100%。基礎用語の確認としては機能しているが、到達度を測りきれていない。記述・応用寄りの設問に配点や比率を寄せる余地がある。
2. **手順・順序づけは科目を越えた課題**：01（AIバイアスの発見・修正手順70%）、02（UI改善36%、トリプルメディアの流れ55%、評価・改善サイクル64%、動画制作から配信まで70%）。情報Ⅰの並べ替えの傾向とも一致する。**プロジェクトの設計・実装・運用では順序の理解が必要**で、次単元以降に影響しうる。
3. **記述は「要点は書けるが、具体例・根拠・両面が不足」**：01は質が高い一方、02は具体例なし、色覚配慮の要点のずれ、トレードオフが未完成の回答が目立った（サンプルは各3件で、断定は避ける）。
4. **権利・規約の実務的な判断**：AI生成物を商用利用する前の確認で、利用規約に触れた回答が3件中0件。単元計画にある「AI生成コンテンツの権利」が授業案（コンテンツ第2時）に記載がなく、肖像権は授業案・小テストとも扱いが確認できない。
5. **関心はプロジェクト連動で引き出されている**：学校の魅力発信（動画、ウェブサイト、QRコード付きパンフレット）に結びつけた案が、メモに見られる。
6. **評価データの偏り**：本データは座学の小テスト・メモのみで、年間計画で60%を占める演習の成果（企画書・制作物・発表・開発計画書・プロジェクトへの貢献）と単元テストが未反映。

### 次年度への申し送り

- **評価資料を揃える**：演習の成果（企画書・制作物・配信設計書・開発計画書・発表・設計記録・振り返りレポート）と単元テストの結果を、`02_評価まとめ.md` に反映して、思考・判断・表現と主体的な態度の評価を見直す。
- **小テストを応用・記述寄りにする**：全員正解が続く基礎用語の選択問題は数を絞るか難度を上げる。概念を新しい事例に当てはめる設問、具体例を求める記述（採点の観点も用意）を増やす。法令の条番号など細部暗記型は、概念・論点を問う形に置き換える。
- **手順・サイクルを自分で操作する活動に**：動画や板書で示すだけでなく、並べ替えや穴埋めで操作させ、最後に自分の言葉で説明させる。
- **授業案と単元計画・小テストをそろえる**：コンテンツ第2時（AI生成コンテンツの権利）、第3時（UI改善プロセス）、第2時（動画制作から配信まで）を授業案に明示する。肖像権を扱うかどうかも決める。
- **01の内容整理**：著作権法47条の5や各国法制は概念・論点レベルにとどめ、浮いた時間を、横断的なケーススタディ（あるAIサービスを題材に、著作権・バイアス・プライバシー・法制を検討）に使う。
- **少人数の運用**：n＝11では正答率より、**個々の誤答を直接見て**設問や指導を判断する。選択科目のため、全員を1クラスとして見る。

### 今後の単元（情報システム・データサイエンス）への見通し

- **03 情報システム**：設計→実装→テスト→運用の流れを、並べ替え・穴埋めで操作する活動にする。生成AIでコードを生成する第6時・第10時の冒頭で、利用規約・出力の検証を確認する。コンテンツ単元のUI・アクセシビリティ（一貫性、色だけで区別しない）を、Webアプリで再び使う。個人データの扱い（QRコード、サーバへの記録）を、ターゲティング広告のトレードオフと結びつける。
- **04 データサイエンス**：KPI・「目標設定→発信→計測→改善」を、運用データの分析で使う。個人データを含む運用データの扱いは、プライバシーの観点から再確認する。
- 評価データは演習中心になるため、**成果物から評価できる資料**（設計記録・分析レポートなど）を残すことが、評価の精度を決める。
