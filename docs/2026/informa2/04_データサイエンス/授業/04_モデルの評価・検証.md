# 第4時：モデルの評価・検証

## 本時の目標

- 訓練データとテストデータに分けてモデルを評価する理由を、過学習と結びつけて説明できる。
- 評価指標（決定係数・RMSE・残差）の意味と使い分けを説明できる。
- 評価の結果をもとに、モデルから「どこまで言えるか」を判断できる。

## キーワード

| 用語 | 説明 |
|---|---|
| 訓練データとテストデータ | 訓練データはモデルを作るのに使うデータ。テストデータは作ったモデルを試すために取っておくデータ |
| 過学習 | 訓練データに合わせすぎて、新しいデータではうまく予測できなくなること |
| 汎化性能 | 学習に使っていない新しいデータに対して、どれだけ正しく予測できるかという力 |
| 残差 | 実際の値と、モデルが予測した値との差 |
| RMSE（二乗平均平方根誤差） | 予測のずれの大きさを1つの数で表したもの。小さいほど予測が実際に近い |
| 決定係数 | モデルがデータにどれだけ当てはまっているかを表す値。訓練データとテストデータの両方で確かめる |

## 準備物・教材

- 教師：授業動画（訓練データとテストデータ／過学習と汎化性能／残差・RMSE・決定係数／評価結果の読み方）、スライド
- 教師：評価・検証の流れの図（データを分ける→訓練データで学習→テストデータで評価→見直す）
- 教師：ワークシート（架空データで作った3つのモデルの比較表：説明変数の数・訓練データの決定係数・テストデータの決定係数・RMSE）
- 教師：前時（演習A①）で生徒が作ったモデルの例（説明変数が少ないものと多いもの）、小テスト（判断型・選択式）
- 生徒：1人1台端末、前時の演習記録シート、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 7分 | 導入（前時の振り返り） | 前時に作ったモデルを振り返る。説明変数を増やすと決定係数が上がったことを確認し、「説明変数を全部入れたモデルがいちばんよいモデルか」を話し合う。「テスト範囲の問題と答えを丸暗記した人は、初めて見る問題も解けるか」というたとえで考える | 前時の生徒のモデルを題材にして、評価・検証を学ぶ必要性を実感させる。ここでは結論を出さず、動画で確かめる |
| 15分 | 展開①（動画視聴・インプット） | 授業動画を視聴：訓練データとテストデータに分ける理由、過学習と汎化性能、評価指標（残差・RMSE・決定係数）の意味、訓練データとテストデータの結果を見比べる読み方 | 評価・検証の流れは図で示す（前単元で手順の並び替えに課題が見られたため）。RMSEは「予測が平均してどのくらいずれるか。目的変数と同じ単位で読める」と説明し、計算式には深入りしない |
| 15分 | 展開②（活用・ワークシート） | 架空データで作った3つのモデルの比較表を読む。①訓練データとテストデータの結果を見比べ、過学習しているモデルを見つけて理由を書く。②「新しいデータの予測に使うならどのモデルを選ぶか」を理由つきで書く。③選んだモデルで「言えること／言えないこと」を整理する | 「訓練では高いがテストでは低い＝過学習」という読み方を型として示す。決定係数は当てはまりの割合、RMSEはずれの大きさというように、指標ごとに分かることが違う点を確認する |
| 8分 | 小テスト（判断型） | 架空の評価結果の表を見て、最も適切な判断を根拠つきの選択肢から選ぶ（例：どのモデルを採用するか／この結果から言えること・言えないこと）。その場で採点し、誤答の多い設問を確認する | 誤答の選択肢は典型的な誤解（「訓練データの決定係数が最も高いモデルがよい」「説明変数は多いほどよい」「RMSEは大きいほどよい」）に対応させる |
| 5分 | まとめ | キーワードと評価・検証の流れを整理する。次週の演習A②では、自分のモデルを訓練／テストに分けて評価し直すことを確認する | 前時の自分のモデルが過学習していないかを次回確かめる、という見通しを持たせる |

## 板書・スライド構成

1. 本時のテーマ：モデルの評価・検証
2. 前時の問い：説明変数は増やすほどよいのか
3. 訓練データとテストデータ（データを分ける）
4. 過学習と汎化性能
5. 評価・検証の流れ（図）：分ける→学習→評価→見直す
6. 評価指標：残差／RMSE／決定係数
7. 読み方：訓練とテストの結果を見比べる
8. 次時：演習A②（重回帰モデルの評価と解釈）

## 本時の評価

- **観点：知識・技能**（評価方法：小テスト・ワークシート）
  - 訓練データとテストデータに分ける理由と、過学習を説明できているか。
  - 残差・RMSE・決定係数の意味を説明できているか。
- **観点：思考・判断・表現**（評価方法：小テスト（判断型）・ワークシート）
  - 評価結果をもとに、採用するモデルと、そこから言えること・言えないことを理由をつけて判断できているか。

## 備考・メモ

- 題材は架空データで完結させ、演習のデータには依存させない。前時の生徒のモデルは導入の話題としてのみ使う。
- 「汎化性能」は過学習と対にして説明する（過学習＝訓練データに合わせすぎて汎化性能が下がった状態）。
- 週1回・2時間連続の2時間目に当たる。第3時（演習A①）の直後に行うため、振り返りは記憶が新しいうちに行える。
