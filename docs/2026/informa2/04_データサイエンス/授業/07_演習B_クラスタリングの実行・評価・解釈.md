# 第7時：演習B｜クラスタリングの実行・評価・解釈

## 本時の目標

- 公開データを標準化し、ノートブック（Google Colab）でk-meansによるクラスタリングを実行できる。
- エルボー法などをもとに、クラスタ数を理由をつけて決められる。
- 各クラスタの特徴を読み取り、名前をつけて説明できる。

## キーワード

| 用語 | 説明 |
|---|---|
| 標準化 | 単位や大きさが違うデータを、同じ基準で比べられるようにそろえる処理 |
| クラスタ数（k） | データをいくつのグループに分けるかという数。分析する人が決める |
| エルボー法 | クラスタ数を増やしたときのまとまり具合の変化をグラフにし、折れ曲がる点から数を決める方法 |
| クラスタの命名 | 各クラスタの平均などの特徴を読み取り、内容を表す名前をつけること |

## 準備物・教材

- 教師：演習B用ノートブック（Google Colab。データの読み込み→標準化→エルボー法→k-meansの実行→クラスタごとの平均と散布図の表示。演習Aと同じ流れで作り、要所に「予想」の欄を設ける）
- 教師：公開データ（政府統計（e-Stat）・気象庁のデータなどを下処理したもの。出典と利用条件を明記）、変数の説明シート
- 教師：k-meansの手順の図（前週の座学で使ったもの）、演習記録シート（予想・クラスタ数と理由・各クラスタの名前と特徴）、観察記録表、生成AIツール
- 生徒：1人1台端末、Google アカウント、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 5分 | 導入 | 前週の復習（k-meansの手順・標準化・エルボー法）。本時の流れ（標準化→クラスタ数の検討→実行→特徴の読み取りと命名）を確認する | 演習Aと同じノートブックの流れであることを伝え、操作の負担を下げる。本時は1時間で完結させる |
| 10分 | 活動①（データの確認と標準化） | データを読み込み、変数を確認する。「いくつのグループに分かれそうか」を予想欄に書く。標準化を実行し、標準化の前後で値がどう変わったかを確認する | 実行前に必ず予想を書かせる。標準化をしない場合に何が起きるかを一言で確認する |
| 12分 | 活動②（クラスタ数の検討と実行） | エルボー法のグラフを表示し、クラスタ数を決めて理由を記録する。k-meansを実行し、クラスタごとの件数・平均・散布図を確認する | クラスタ数は1つに決まらなくてよい。「なぜその数にしたか」を必ず書かせる。コードは生成AIと協働で扱う |
| 15分 | 活動③（特徴の読み取り・命名・提出） | **基本課題**：各クラスタの平均から特徴を読み取り、名前をつけて説明を書く。**発展課題**：クラスタ数を変えて実行し直し、どちらの分け方が説明しやすいかを比べて理由を書く。演習記録シートとノートブックを提出する | 名前は特徴の根拠（どの変数が高い・低いか）とセットで書かせる。基本課題／発展課題のどこまで進んだか、止まった場面を観察記録に残す |
| 8分 | まとめ | 数名がつけたクラスタの名前と理由を共有する。予想とのちがいを確認する。同じデータでもクラスタ数や解釈が人によって違うことを取り上げ、次時（目的に応じた手法の選び方）へつなぐ | 「正解が1つではない」ことを、分析の弱点ではなく特徴として押さえる |

## 本時の評価

- **観点：知識・技能**（評価方法：演習提出物（ノートブック・演習記録シート））
  - 標準化とk-meansを実行し、クラスタごとの特徴を読み取れているか。
- **観点：思考・判断・表現**（評価方法：演習提出物（解釈の記述））
  - クラスタ数を理由をつけて決め、各クラスタの特徴を根拠をもって説明できているか。
- **観点：主体的に学習に取り組む態度**（評価方法：観察記録）
  - 予想と結果を比べたり、クラスタ数を変えて確かめたりしながら取り組んでいるか。
