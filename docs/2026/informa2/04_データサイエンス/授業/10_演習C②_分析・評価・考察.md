# 第10時：演習C②｜分析・評価・考察

## 本時の目標

- 自分で選んだ手法でデータを分析し、モデルや結果を評価できる。
- 分析結果の意味と限界（相関と因果、データの偏り、過学習）を整理できる。
- 分析前の予想と結果の違いを考察し、根拠のある改善提案を考えられる。

## キーワード

| 用語 | 説明 |
|---|---|
| モデルの評価 | 作ったモデルがどのくらい信頼できるかを、指標やグラフで確かめること |
| 結果の解釈 | 出てきた数値やグラフが何を意味するかを、言葉で説明すること |
| 分析の限界 | その分析からは言えないこと。相関と因果の区別、データの偏り、過学習などが関わる |
| 予想との違い | 分析前の予想と実際の結果とのずれ。その理由を考えることが考察の入口になる |
| 改善提案 | 分析結果を根拠にして、次にどうすればよくなるかを具体的に示すこと |

## 準備物・教材

- 教師：演習C用ノートブック（前時の続き。重回帰分析・クラスタリングの節で、書き換えるだけで評価まで出る）、演習A・Bのノートブックと分析レポート（見返し用）
- 教師：分析レポート（前時の続き。本時は3 分析の結果・4 評価・5 解釈を書き、6 結論は下書きまで）。評価で確かめること（重回帰分析：訓練/テスト分割・決定係数・RMSE・残差／クラスタリング：標準化・クラスタ数の根拠・クラスタの特徴）は、テンプレートの「4 評価」とノートブックの出力に示してある
- 教師：目的と手法の対応表、評価・検証の流れの図、観察記録表、生成AIツール
- 生徒：1人1台端末、前時に書いた分析レポートとノートブック、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 3分 | 導入 | レポートの1〜3（前時に書いた問い・予想・データ・手法）を読み返し、本時の流れ（分析→評価→解釈と限界→予想との違い→改善提案）と、本時に書くスライド（3の結果・4・5）を確認する | 第9時から続けて行うため、導入は短くする |
| 15分 | 活動①（分析の実行） | 選んだ手法で分析を実行する。重回帰分析の場合は説明変数を決めて実行し、クラスタリングの場合はクラスタ数を検討して実行する。結果のグラフや表を1〜2点選び、レポートの「3 分析」に貼って、読み取れることを添える | ノートブックは書き換えるだけで結果が出るので、時間を結果の読み取りに回させる。もう一歩調べたいときのコードは生成AIと協働で扱う。手法の選択で止まっている生徒には、問いの目的に立ち返らせる |
| 12分 | 活動②（モデルの評価） | レポートの「4 評価」に示した項目に沿って結果を確かめる。重回帰分析は訓練/テスト分割・決定係数・RMSE・残差を確認し、クラスタリングはクラスタ数の根拠とクラスタごとの特徴を確認する。必要に応じてモデルを見直す。確かめた内容をレポートの「4 評価」に書く | 評価の読み取りで止まる生徒が多いと想定される。評価・検証の流れの図を示し、「訓練とテストを見比べる」「クラスタを説明できるか」という読み方を確認する |
| 15分 | 活動③（解釈・限界・考察） | **基本課題**：結果を言葉で説明し、言えること・言えないこと（限界）を整理する（レポートの「5 解釈」）。分析前の予想と結果を比べ、**違いとその理由**を書く（同じく「5 解釈」）。**発展課題**：予想が外れた理由を追加の集計やグラフで調べる。分析結果を根拠に、改善提案（例：来年の文化祭の運営への提案）を考え、レポートの「6 結論」に下書きする | 予想が当たった場合も「なぜ当たったと言えるか」を書かせる。限界には、相関と因果・データの偏り・過学習のうち当てはまるものを必ず1つ以上書かせる |
| 5分 | まとめ | レポートの3〜5が書けているかを確認する。次週（レポート作成・最終発表）は、6 結論の仕上げと全体の見直しから始めることを確認する | 書きためたスライドがそのままレポートになり、発表にも使うことを伝え、次週の作業を「仕上げ」だけにする |

## 板書・スライド構成

1. 本時のテーマ：演習C②｜分析・評価・考察
2. 流れ：分析→評価→解釈と限界→予想との違い→改善提案
3. 評価で確かめること（重回帰分析／クラスタリング。テンプレートの「4 評価」と同じ）
4. 考察の型：言えること／言えないこと（限界）／予想との違いとその理由
5. 次時：レポート作成・最終発表（必須項目の確認）

## 本時の評価

- **観点：知識・技能**（評価方法：ノートブック・分析レポートの「3 分析」「4 評価」）
  - 選んだ手法を実行し、評価指標やグラフから結果を読み取れているか。
- **観点：思考・判断・表現**（評価方法：分析レポートの「4 評価」「5 解釈」）
  - 評価結果をもとに、結果の意味と限界を踏まえた結論を、根拠をもって述べられているか。
  - 予想と結果の違いとその理由を考察できているか。
- **観点：主体的に学習に取り組む態度**（評価方法：観察記録）
  - 結果を検証したり、予想が外れた理由を調べたりしながら、分析を深めようとしているか。
- 観察記録には、止まった場面（手法の選択／評価の読み取り／結論の書き方）、予想と結果の違いへの反応、助言を残す。

## 備考・メモ

- 週1回・2時間連続の2時間目に当たる。第9時と合わせて100分で「問い→分析→考察」までを進める。
- 分析が終わらなかった生徒は、次週の冒頭までにレポートの3〜5（結果・評価・限界・予想との違い）が書けるよう、進め方を個別に確認する。
- 手法を指定しないため、同じデータでも生徒によって手法や結論が違う。発表での比較材料になるので、違いをそのまま生かす。
