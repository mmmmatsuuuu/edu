# 第9時：演習C①｜データの選択と問いの設定

## 本時の目標

- データメニューから分析するデータを選び、その構造（行数・変数・欠損）を確認できる。
- 問いカードを使って、問いと分析の目的を設定できる。
- 分析の前に結果を予想し、目的に合った手法を自分で選んで、理由を説明できる。

## キーワード

| 用語 | 説明 |
|---|---|
| 問い | データから明らかにしたいこと。分析の出発点になる |
| データメニュー | 教師が用意した、分析に使えるデータの一覧。この中から自分で選ぶ |
| 問いカード | 「〇〇は△△で説明できるか」などの型に変数を当てはめて、問いを作るためのカード |
| 予想（仮説） | 分析する前に立てる、結果についての見通し。分析後に答え合わせをする |
| 前処理 | 分析の前にデータを整える作業。欠損値・外れ値の処理や標準化などがある |

## 準備物・教材

- 教師：データメニュー（文化祭データ（ゲートを通過した場合）・リハーサルデータ・合成データ・オープンデータ。各データの変数の説明と出典を添える。2026年度はオープンデータから作った3つ：自転車シェア・都市の食卓と気候・都道府県のくらし）
- 教師：問いカード（目的の型：「〇〇は△△で説明できるか」「〇〇を予測できるか」「〇〇はいくつかのタイプに分けられるか」）
- 教師：分析レポートのテンプレート（Google スライド。演習A・Bと同じ7枚：タイトル／1 課題設定／2 データ収集／3 分析／4 評価／5 解釈／6 結論。各スライドで押さえることだけを示し、細かい欄は作らない。必須項目には「必ず入れる」の印をつける）、ルーブリック（本時の導入で示す）
- 教師：演習C用ノートブック（Google Colab。データの読み込み・確認・前処理と、重回帰分析・クラスタリングの両方の節を用意し、目的変数・説明変数・クラスタ数などを書き換えるだけで評価まで進められるようにする。Excel と CSV のどちらも読める）、目的と手法の対応表（第8時のもの）、観察記録表、生成AIツール
- 生徒：1人1台端末、演習A・Bのノートブックと分析レポート、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 5分 | 導入 | 演習Cの全体像（本時：データの選択と問いの設定→次時：分析・評価・考察→第11時：レポート作成・発表）と、ルーブリック（必須項目：手法の選択理由・評価・限界・予想と結果の違い／持ち込みの加点）を確認する。分析レポートのテンプレートを受け取り、**本時から3時間かけて少しずつ書いていく**こと（本時は1 課題設定・2 データ収集と、3 分析の「手法と選んだ理由」）を確認する | 手法は指定しないこと、選んだ理由を必ず書くことを伝える。レポートの形は演習A・Bと同じなので、書き方の説明は短くし、作業の時間を確保する。合成データを使う場合は、合成データであることを明示する |
| 10分 | 活動①（データの選択と構造の確認） | データメニューからデータを選ぶ（自分で見つけたデータを持ち込んでもよい）。ノートブックで読み込み、行数・変数・基本統計量・欠損の有無を確認する。選んだ理由とデータの質（出どころ・利用条件・大きさ・個人情報・問いに合うか）をレポートの「2 データ収集」に書く | 興味で選んでよいが、「説明変数と目的変数がある」「グループ分けできる」のどちらに向くデータかを確認させる。持ち込みは申請・審査をせず、質の確認を生徒に任せる（評価に含める）。使えないと分かったらメニューに乗り換えてよいことを伝える。データ選択の理由を観察記録に残す |
| 12分 | 活動②（問いと目的の設定） | 問いカードの型に、選んだデータの変数を当てはめて問いを作る。その問いの目的が説明・予測・グルーピングのどれに当たるかを書く（レポートの「1 課題設定」。問いはタイトルにもなる） | 問いの設定は本時の前半で完了させる。問いが立てられずに止まっている生徒には、型と変数の組み合わせの例を示す。止まった場面を観察記録に残す |
| 10分 | 活動③（予想と手法の選択） | **分析の前に**、結果の予想をレポートの「1 課題設定」に書く（例：「どの変数が一番効くか」「何タイプに分かれるか」）。目的と手法の対応表をもとに手法を選び、理由をレポートの「3 分析」に書く | 予想は必ず分析の前に書かせる。手法は教えず、「目的は何か」「答え（ラベル）はあるか」と問い返して選ばせる |
| 10分 | 活動④（前処理） | **基本課題**：ノートブックの箱ひげ図などで欠損値・外れ値を確認し、どう処理したかと理由をレポートの「2 データ収集」に書く（クラスタリングを選んだ場合は標準化も行う）。**発展課題**：処理の前後で基本統計量やグラフがどう変わったかを確かめて記録する | 外れ値は入力ミスか意味のある値かを確かめてから処理させる。処理の内容は次時の「限界」の記述にも使うことを伝える |
| 3分 | まとめ | レポートの1・2と、3の「手法と選んだ理由」が書けているかを確認し、次時（分析・評価・考察）で行うことを確認する | 続けて第10時に入るため、まとめは短くする |

## 板書・スライド構成

1. 本時のテーマ：演習C①｜データの選択と問いの設定
2. 演習Cの全体像と、分析レポートのテンプレート（演習A・Bと同じ7枚。本時は1・2と3の「手法と選んだ理由」）・ルーブリック
3. データメニューと、持ち込みのときに確かめること（出どころ・利用条件・大きさ・個人情報・問いに合うか）
4. 問いカードの型（説明できるか／予測できるか／タイプに分けられるか）
5. 順番：問い→目的→**予想**→手法の選択→前処理
6. 目的と手法の対応表（第8時の再掲）

## 本時の評価

- **観点：思考・判断・表現**（評価方法：分析レポートの「1 課題設定」「3 分析」の手法の選択理由）
  - 問いと目的を設定し、目的に応じて手法を選び、その理由を説明できているか。
- **観点：知識・技能**（評価方法：ノートブック・分析レポートの「2 データ収集」）
  - データの質（出どころ・利用条件・大きさ・個人情報・問いに合うか）と構造を確認し、欠損値・外れ値を適切に処理できているか。
- **観点：主体的に学習に取り組む態度**（評価方法：観察記録）
  - データに主体的に向き合い、問いを立て直しながら取り組んでいるか。自分で見つけたデータを持ち込み、その質を確かめた場合は加点する。
- 観察記録には、データ選択の理由、問いの立てやすさ、止まった場面・行動・助言を残す。

## 備考・メモ

- 分析レポートは第11時にまとめて書かせず、本時に配るテンプレート（Google スライド）へ少しずつ書かせる（本時：1・2と3の「手法と選んだ理由」、第10時：3の結果・4・5、第11時：6と見直し）。演習A・Bと同じ7枚の構成なので、細かい書き方は演習A・Bのレポートを見返させる。
- 週1回・2時間連続の1時間目に当たり、続けて第10時（分析・評価・考察）を行う。本時で問いが決まらないと次時に進めないため、問いの設定を最優先で支援する。
- 文化祭データを使えるかどうかは、情報システム単元第14時のゲート判断による。使えない場合もデータメニューだけで演習Cが成立するようにしておく（2026年度は文化祭データが集まらず、データメニューと持ち込みで行う）。
- データに参加者ID以外の個人情報が含まれないことを、配布前に確認する。
