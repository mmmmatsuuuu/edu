# 第6時：クラスタリング

## 本時の目標

- クラスタリングが教師なし学習であることを理解し、距離をもとにデータをグループに分ける考え方を説明できる。
- k-meansの手順と、標準化が必要な理由を説明できる。
- クラスタ数の決め方（エルボー法など）と、正解のない学習の結果をどう評価・解釈するかを判断できる。

## キーワード

| 用語 | 説明 |
|---|---|
| クラスタリング | 似たデータどうしを集めて、いくつかのグループ（クラスタ）に分ける方法 |
| 距離 | データどうしがどれだけ似ているかを表す数。小さいほど似ている |
| k-means（k平均法） | 分けたいグループの数kを先に決め、各グループの中心に近いデータを集めることをくり返す方法 |
| 標準化 | 単位や大きさが違うデータを、同じ基準で比べられるようにそろえる処理 |
| エルボー法 | クラスタ数を増やしたときのまとまり具合の変化をグラフにし、折れ曲がる点から数を決める方法 |
| クラスタの解釈 | 各クラスタの特徴を読み取り、どんなグループかを言葉にして名前をつけること |

## 準備物・教材

- 教師：授業動画（教師なし学習とクラスタリング／距離／k-meansの手順／標準化／エルボー法／結果の解釈）、スライド
- 教師：k-meansの手順の図（中心を置く→近い中心に割り当てる→中心を動かす→くり返す）
- 教師：ワークシート（架空の顧客データ：来店回数・1回あたりの購入金額の散布図／エルボー法のグラフ／クラスタごとの平均の表）
- 教師：小テスト（判断型・選択式）
- 生徒：1人1台端末、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 5分 | 導入 | 前時までの復習（重回帰分析＝答えのある学習）。架空の顧客データの散布図を見て、「答え（ラベル）がないとき、似た客どうしをどう分けるか。いくつのグループに見えるか」を考える | 第1時の「教師あり／教師なし」の区別を思い出させる。人によってグループの数が違うことを取り上げ、クラスタ数の決め方への問いにする |
| 15分 | 展開①（動画視聴・インプット） | 授業動画を視聴：クラスタリングとは、距離で「似ている」を測る、k-meansの手順、標準化が必要な理由、エルボー法によるクラスタ数の検討、クラスタの特徴の読み取りと命名 | k-meansの手順は図で示し、順を追って確認する。標準化は「年収（万円）と年齢（歳）のように単位や大きさが違うと、大きい数の変数だけで距離が決まってしまう」という例で説明する |
| 17分 | 展開②（活用・ワークシート） | ①散布図の上で、k-meansの手順を1回分だけ手作業で行う（各点を近い中心に割り当て、中心を動かす）。②エルボー法のグラフを読み、クラスタ数の候補とその理由を書く。③クラスタごとの平均の表を読み、各クラスタに名前をつけて特徴を説明する | 手作業は手順を体感させるためのもので、点の数は少なくする。クラスタ数は1つに決まらない場合があり、「分けた結果を説明できるか」も判断材料になることを伝える |
| 8分 | 小テスト（判断型） | 場面を読んで選択肢から選ぶ（例：標準化が必要な場面はどれか／エルボー法のグラフからクラスタ数を選ぶ／クラスタリングの結果から言えること・言えないこと）。その場で採点し、誤答の多い設問を確認する | 誤答の選択肢は典型的な誤解（「クラスタリングには正解のグループがある」「クラスタ数は多いほどよい」「クラスタリングと分類は同じ」）に対応させる |
| 5分 | まとめ | キーワードを整理する。正解がない学習では「結果を説明できるか・役に立つか」で評価することを確認する。次週の演習Bでは、公開データでクラスタリングを実行することを予告する | 重回帰分析（決定係数などで評価）との違いを対比して押さえる |

## 板書・スライド構成

1. 本時のテーマ：クラスタリング
2. 教師なし学習：答え（ラベル）のないデータを分ける
3. 距離：似ている＝近い
4. k-meansの手順（図）：中心を置く→割り当てる→中心を動かす→くり返す
5. 標準化：単位や大きさをそろえる
6. クラスタ数の決め方：エルボー法
7. 結果の評価と解釈：特徴を読み取り、名前をつける
8. 分類（教師あり）とクラスタリング（教師なし）の違い

## 本時の評価

- **観点：知識・技能**（評価方法：小テスト・ワークシート）
  - クラスタリング・距離・k-meansの手順・標準化を説明できているか。
  - エルボー法のグラフやクラスタごとの平均の表を読み取れているか。
- **観点：思考・判断・表現**（評価方法：小テスト（判断型）・ワークシート）
  - クラスタ数を理由をつけて判断し、クラスタの特徴を根拠をもって説明できているか。
