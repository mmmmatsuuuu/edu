# 第8時：目的に応じた手法の選び方

## 本時の目標

- 分析の目的（説明・予測・グルーピング）と手法（重回帰分析・クラスタリング）の対応を説明できる。
- 前処理（欠損値・外れ値の処理・標準化）の必要性を理解し、場面に応じた処理を判断できる。
- 手法の誤用の例（相関と因果の混同、データの偏り）をもとに、分析結果がどこまで言えるかを判断できる。

## キーワード

| 用語 | 説明 |
|---|---|
| 分析の目的（説明・予測・グルーピング） | 何のために分析するか。関係を説明する、値を予測する、似たものに分ける、の3つに整理できる |
| 手法の選択 | 分析の目的とデータの形に合った分析方法を、理由をもって選ぶこと |
| 前処理 | 分析の前にデータを整える作業。欠損値・外れ値の処理や標準化などがある |
| 欠損値 | 記録されていない、抜けているデータ |
| 外れ値 | ほかのデータから大きく離れた値。入力ミスの場合と、意味のある値の場合がある |
| データの偏り | 集めたデータが一部の人や場面にかたよっていること。結論を当てはめられる範囲がせまくなる |

## 準備物・教材

- 教師：授業動画（分析の目的と手法の対応／前処理（欠損値・外れ値・標準化）／手法の誤用の例）、スライド
- 教師：目的と手法の対応表、手法を選ぶ流れの図（答え（ラベル）があるか→当てたいのは数値か→…）
- 教師：ワークシート（分析したい場面のカード／欠損値と外れ値を含む架空の表／誤用の事例）
- 教師：小テスト（判断型・選択式）、演習Cのデータメニュー（確定版）と問いカードの見本
- 生徒：1人1台端末、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 5分 | 導入 | 前時までの復習（重回帰分析とクラスタリング）。「同じ売上データでも、『売上に何が効いているか知りたい』ときと『客をタイプに分けたい』ときで、使う手法は同じか」を考える | 手法から考えるのではなく、目的から考えるという本時の視点を示す |
| 15分 | 展開①（動画視聴・インプット） | 授業動画を視聴：分析の目的（説明・予測・グルーピング）と手法の対応、前処理の種類と必要性、手法の誤用の例（相関を因果と言い切る、偏ったデータから全体を語る） | 説明と予測はどちらも重回帰分析を使えるが、重視する点が違う（説明＝係数の解釈、予測＝テストデータでの評価）ことを対応表で示す。手法を選ぶ流れは図で示す |
| 17分 | 展開②（活用・ワークシート） | ①場面カードを読み、目的（説明・予測・グルーピング）と使う手法を選び、理由を書く。②架空の表から欠損値と外れ値を見つけ、どう処理するかとその理由を書く。③誤用の事例を読み、どこが問題か、どう言い直せばよいかを書く | 外れ値は「消す」だけが正解ではなく、入力ミスか意味のある値かを確かめてから判断することを押さえる。演習Cでそのまま使う判断なので、理由を書く型を示す |
| 8分 | 小テスト（判断型） | 場面を読んで、最も適切な手法と根拠の組を選ぶ。架空の表や分析結果から、言えること・言えないことを選ぶ。その場で採点し、誤答の多い設問を確認する | 誤答の選択肢は典型的な誤解（「グループに分けたいから重回帰分析」「外れ値は必ず消す」「一部のデータの結果を全体に当てはめる」）に対応させる |
| 5分 | まとめ | キーワードと目的・手法の対応を整理する。次週からの演習Cの進め方（データメニューから選ぶ→問いカードで問いを作る→予想→手法を自分で選ぶ）を予告する | 演習Cでは手法を指定しないことを伝える。持ち込みデータの申請は今週までであることを確認する |

## 板書・スライド構成

1. 本時のテーマ：目的に応じた手法の選び方
2. 分析の目的：説明／予測／グルーピング
3. 目的と手法の対応表（重回帰分析・クラスタリング）
4. 手法を選ぶ流れ（図）
5. 前処理：欠損値・外れ値・標準化
6. 誤用の例：相関と因果の混同／データの偏り
7. 「どこまで言えるか」を確かめる
8. 次時：演習C（データの選択と問いの設定）

## 本時の評価

- **観点：知識・技能**（評価方法：小テスト・ワークシート）
  - 分析の目的と手法の対応、前処理の種類と必要性を説明できているか。
- **観点：思考・判断・表現**（評価方法：小テスト（判断型）・ワークシート）
  - 場面に応じて手法を選び、その理由を説明できているか。
  - 誤用の事例について、結果がどこまで言えるかを根拠をもって判断できているか。

## 備考・メモ

- 演習Cの直前に行う座学であり、本時の「目的と手法の対応」が演習Cの手法選択の拠り所になる。対応表と流れの図は演習Cでも配布する。
- 第4週に当たるため、演習Cのデータメニュー（文化祭データのゲート判断の結果・代替データ・承認済みの持ち込みデータ）を本時までに確定させておく。
- 題材は架空データで完結させ、演習Cのデータには依存させない。
