# 第1時：データ分析の流れと機械学習の基礎

## 本時の目標

- 情報Ⅰで学んだデータの種類・基本統計量・可視化を思い出し、データ分析の流れ（収集→整理→分析→可視化→解釈）の中に位置づけて説明できる。
- 機械学習とは何かを、モデル・特徴量・ラベルという言葉を使って説明できる。
- 教師あり学習（回帰・分類）・教師なし学習・強化学習の違いを理解し、場面に応じてどれに当たるかを判断できる。

## キーワード

| 用語 | 説明 |
|---|---|
| データの種類（量的データ・質的データ） | 量的データは数値で表され大きさに意味があるデータ（例：気温・売上）。質的データは種類や区分を表すデータ（例：曜日・天気） |
| 基本統計量 | データ全体の特徴を1つの数で表したもの。平均値・中央値などの代表値と、分散・標準偏差などの散らばりを表す値がある |
| 機械学習 | 大量のデータからコンピュータがパターン（きまり）を見つけ出し、予測や判断に使う技術。教師あり学習・教師なし学習・強化学習に大きく分けられる |
| モデル | データから学習して得られた「入力から出力を求めるしくみ」。学習でモデルを作り、新しいデータに当てはめて予測する |
| 特徴量とラベル | 特徴量は予測の手がかりにするデータ（例：気温・曜日）。ラベルは当てたい答え（例：売上） |
| 教師あり学習 | 答え（ラベル）のついたデータで学習し、新しいデータの答えを予測する方法。数値を予測する回帰と、種類を予測する分類がある |
| 教師なし学習 | 答え（ラベル）のないデータから、似たものどうしのグループなどの構造を見つけ出す方法 |

## 準備物・教材

- 教師：授業動画（データ分析の流れ／機械学習とは／教師あり・教師なし・強化学習／モデル・特徴量とラベル／回帰と分類）、スライド
- 教師：復習診断シート（架空データの表とグラフ。データの種類・基本統計量・グラフの読み取りを問う）、ワークシート（場面カードの仕分け）
- 教師：小テスト（判断型・選択式。Google フォームなど、その場で採点できる形）
- 生徒：1人1台端末、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 8分 | 導入（復習診断） | 単元の見通しを確認する（機械学習を学び、最後に文化祭の運用データなどを分析して報告する）。続けて復習診断シートに取り組む：架空の売上データの表とグラフを見て、各列が量的データか質的データか、平均値と中央値のどちらが代表値にふさわしいか、グラフから何が読み取れるかを答える | 情報Ⅰの内容は新しく教え直さず、圧縮して確認する。診断の結果から、つまずいている生徒と内容を把握し、以降の座学・演習の支援に使う |
| 15分 | 展開①（動画視聴・インプット） | 授業動画を視聴：データ分析の流れ（収集→整理→分析→可視化→解釈）、機械学習とは（データからパターンを学習してモデルを作り、新しいデータを予測する）、特徴量とラベル、教師あり学習（回帰・分類）・教師なし学習・強化学習の違い | 動画は架空データ・一般的な例（売上の予測、迷惑メールの判定、顧客のグループ分け、ゲームAI）で完結させる。分類は「種類を当てる教師あり学習」として紹介にとどめ、実行は扱わない |
| 15分 | 展開②（活用・ワークシート） | ①場面カード（例：「来月の来客数を予測したい」「写真が犬か猫か見分けたい」「会員を買い方の似たグループに分けたい」「ロボットに歩き方を覚えさせたい」）を、教師あり（回帰／分類）・教師なし・強化学習に仕分ける。②教師あり学習のカードについて、特徴量とラベルに当たるものを書き出す。ペアで理由を説明し合う | 仕分けの結果だけでなく「答え（ラベル）があるか」「当てたいのは数値か種類か」という判断の手がかりを言葉にさせる。迷ったカードを全体で取り上げる |
| 8分 | 小テスト（判断型） | 場面を読んで選択肢から選ぶ小テストに取り組む（例：ある分析の場面がどの学習に当たるか、根拠つきの選択肢から選ぶ／架空の表から特徴量とラベルの組を選ぶ）。その場で採点し、誤答の多い設問を確認する | 誤答の選択肢は典型的な誤解（「データが多ければ教師あり」「グループ分けは分類」など）に対応させる |
| 4分 | まとめ | キーワードを整理する。次時（重回帰分析）は、教師あり学習のうち「数値を予測する回帰」を詳しく学ぶことを確認する | 分類とクラスタリング（グループ分け）の違いは第6時でもう一度扱うことを予告する |

## 板書・スライド構成

1. 本時のテーマ：データ分析の流れと機械学習の基礎／単元の見通し
2. 復習：データの種類（量的・質的）／基本統計量（代表値・散らばり）／グラフの使い分け
3. データ分析の流れ：収集→整理→分析→可視化→解釈
4. 機械学習とは：データ→学習→モデル→予測
5. 特徴量（手がかり）とラベル（答え）
6. 3つの学習：教師あり（回帰・分類）／教師なし／強化学習
7. 見分け方：答えがあるか → 数値か種類か
8. 次時：重回帰分析

## 本時の評価

- **観点：知識・技能**（評価方法：小テスト・復習診断シート）
  - 機械学習・モデル・特徴量とラベルを説明できているか。
  - 教師あり学習・教師なし学習・強化学習の違いを説明できているか。
- **観点：思考・判断・表現**（評価方法：小テスト（判断型）・ワークシート）
  - 場面に応じて、どの学習に当たるかを理由をつけて判断できているか。
- 復習診断シートは成績には入れず、以降の支援の資料として使う。

## 備考・メモ

- 第1時は診断を兼ねる。情報Ⅰの内容でつまずいている生徒は、第3時以降の演習で重点的に支援する。
- 週1回・2時間連続の1時間目に当たる。続く第2時（重回帰分析）で、本時の「教師あり学習・回帰」をそのまま引き継ぐ。
- 「分類」と「クラスタリング」は混同しやすい。本時は「答え（ラベル）があるかどうか」で区別することだけを押さえる。
