# 第11時：演習C③｜レポート作成・最終発表

## 本時の目標

- 第9時から書きためてきたテンプレートを仕上げ、手法の選択理由・評価・限界・予想と結果の違いを含む分析レポートを完成させられる。
- 分析の結果と結論を、根拠を示しながら短く発表できる。
- ほかの人の発表を聞いてフィードバックを伝え合い、年間プロジェクト全体を総括できる。

## キーワード

| 用語 | 説明 |
|---|---|
| 分析レポート | 問い・手法の選択理由・結果・評価・限界・結論をまとめた報告書 |
| 根拠 | 結論を支えるデータや分析結果。「なぜそう言えるか」を示すもの |
| 手法の選択理由 | なぜその分析方法を選んだかを、分析の目的と結びつけて説明したもの |
| フィードバック | 発表やレポートに対して、よい点や改善点を伝え合うこと |

## 準備物・教材

- 教師：分析レポートのテンプレート（第9〜10時に①〜⑨を記入済みのもの。本時は⑩結論・改善提案の仕上げと全体の見直しを行う）、必須項目のチェックリスト
- 教師：発表の進め方（1人あたりの時間・話す項目）、フィードバックシート（よかった点・質問）、評価のルーブリック
- 教師：提出先（Google Classroom）
- 生徒：1人1台端末、第9〜10時に記入したテンプレートとノートブック、Google Classroom
- 教科書：情報Ⅱ（東京書籍）第3章

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 3分 | 導入 | 本時の流れ（レポートの仕上げ→短い発表→フィードバック→総括）を確認する。チェックリストで、テンプレートの①〜⑨が埋まっているかを各自確かめる | 本時の中心はレポートの完成であり、発表は要点の共有であることを伝える |
| 15分 | 活動①（レポートの仕上げ） | テンプレートの⑩結論・改善提案を書き上げる。①〜⑨を読み返し、問い→結果→結論のつながりと、必須項目（手法の選択理由・評価・限界・予想と結果の違い）がそろっているかを確かめて直す。レポートを提出する | 新しく書くのは⑩だけにし、残りは見直しにとどめる。結論の書き方で止まっている生徒には、「問い→結果→だから何が言えるか」の順で書かせる。第10時までに⑥〜⑨が埋まっていない生徒を優先して支援する |
| 17分 | 活動②（短い発表） | レポートを画面に映し、1人ずつ要点を話す（問い→選んだ手法と理由→結論→予想との違い）。発表用の資料は別に作らない。聞き手はフィードバックシートに、よかった点と質問を書く | 1人あたりの時間は人数に応じて決める（2〜3分を目安に、少人数を生かして全員が話す）。同じデータで手法や結論が違う例を取り上げ、目的によって手法が変わることを確認する |
| 10分 | 活動③（フィードバックと総括） | フィードバックシートを交換して読む。年間プロジェクト（デジタルスタンプラリーの企画・制作・運用・分析）全体を振り返り、データを分析したことで分かったことを共有する | 情報システム単元で集めたデータが分析につながったことを確認し、プロジェクト全体の締めくくりにする |
| 5分 | まとめ | レポートの提出状況を確認する。次時（単元テストと振り返り）の範囲と形式を確認する | 続けて第12時に入るため、提出の確認を確実に行う |

## 板書・スライド構成

1. 本時のテーマ：演習C③｜レポート作成・最終発表
2. チェックリスト：テンプレートの①〜⑨／必須項目（手法の選択理由・評価・限界・予想と結果の違い）
3. 本時に書くこと：⑩結論・改善提案
4. 発表で話す項目：問い→手法と理由→結論→予想との違い
5. 聞き方：よかった点・質問
6. プロジェクト全体の総括：企画→制作→運用→分析

## 本時の評価

- **観点：思考・判断・表現**（評価方法：分析レポート・発表）
  - 目的に応じて手法を選び、その理由を説明できているか。
  - 評価結果をもとに、結果の意味と限界を踏まえた結論を、根拠をもって述べられているか。
  - 予想と結果の違いとその理由を考察できているか。
- **観点：知識・技能**（評価方法：分析レポート）
  - 手法を正しく実行し、結果を正しく読み取れているか。
- **観点：主体的に学習に取り組む態度**（評価方法：観察記録・フィードバックシート）
  - ほかの人の発表から学び、自分の分析を見直そうとしているか。
- 評価の中心は分析レポートとし、観点別評価（思考・判断・表現）の総括的評価に用いる。発表は要点を伝えられているかを確認する程度にとどめる。

## 備考・メモ

- レポートは、第9時に配ったテンプレートへ3時間かけて少しずつ記入する（第9時：①〜⑤、第10時：⑥〜⑨、本時：⑩と見直し）。本時にゼロから書かせない。
- テンプレートは、題材や手法が違っても共通して押さえる最低限の項目だけで構成する。手法によって内容が変わる⑥結果・⑦評価には、重回帰分析・クラスタリングそれぞれの記入の手引きを添える。
- 発表は本時の中心ではないため、発表用の資料は作らせず、レポートをそのまま映して話す。
- 週1回・2時間連続の1時間目に当たり、続けて第12時（単元テストと振り返り）を行う。
