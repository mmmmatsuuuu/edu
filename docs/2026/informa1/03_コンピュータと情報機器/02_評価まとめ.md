## 気づき・課題

### 目標の達成度

- **ハードウェア・ソフトウェアの構成と役割の理解（第1・2時）**：概ね達成。5大装置・CPUサイクル・OS/API は80〜90%台。
- **論理回路の基本（AND・OR・NOT）**：基本回路は約80%で達成。ただし組み合わせ回路（NAND 66%、XOR 39%、半加算 43〜51%）は部分的達成にとどまる。
- **整数・負の数・小数の2進数表現と誤差**：概念（誤差の種類 52〜68%）は半数強。補数・加算の計算は**到達していない**（35〜55%）。単元の評価基準にある「説明できる」には届いているが、計算で使うところまでは届いていない。
- **目的に応じた情報機器の選択・活用**：直接測る小テスト設問が少ない。応用寄りの問い（組み込みシステム 67%、RAM 8GB 61%、映像・音声のインターフェース 62%、動画書き出しで強化する要素 58%）は低めで、**知識を具体的な場面に当てはめる力は途上**。第5時の単元テストで確認したい。
- 総じて、**概念理解は目標に到達、計算・応用は途上**という結果。

### 授業構成・時間配分

- 各時とも「動画視聴＋ワークシート／プリント」の構成で、動画が18〜25分を占める。概念系の第1・2時はこの構成で高定着が得られている。
- **第3時（論理回路）**：導入8分で「1＋1＝10」を押さえたが、1303 Q8（1+1の和=0・桁上がり=1）は43%。**XOR＝和、AND＝桁上がりという対応づけまで届いていない**。動画20分で AND・OR・NOT・XOR・組み合わせ回路・半加算回路を扱うため情報量が多く、練習15分で真理値表の穴埋めに加え組み合わせ回路・半加算回路の確認まで行うのは時間的に厳しい。
- **第4時（情報の内部表現）**：ウォームアップ12分で進数変換を手を動かして確認する設計は計画どおり。ただし本題（補数・固定小数点・浮動小数点・誤差5種）は動画18分＋練習13分で、**1コマに詰め込みすぎ**。補数の加算（4ビット加算 40〜53%、7−2の手順 35%）は動画視聴後の練習が短く、反復が不足した可能性が高い。
- 第5時の単元テストは35分（導入5分・まとめ10分）。時間配分は妥当と思われるが、結果は未確認。なお単元計画の備考には「テスト返却と解説」とあるが、第5時の展開は単元テスト実施と振り返りシートで、返却・解説の時間がない。

### ストロングポイント（得意）

- **ハードウェアの基本知識**：5大装置（93%）、CPUサイクル（88%）、クロック周波数（83%）、主記憶の特徴（80%）。
- **OS・APIの概念**：OSの役割 83%、API 83%。メモには三層構造（アプリ→OS→ハードウェア）やAPIの役割を整理した記述が多い。
- **記述による説明**：主記憶/補助記憶の電源に着目した説明、OSの「交通整理係」、OR と XOR の違いなどは、キーワードを使って簡潔に説明できている回答が目立つ。前単元で見られた「なぜそうなるかを言葉で説明する」強みは維持されている。
- **基本論理回路の理解**：AND と電気回路（直列）の対応（81%）、NOT（82%）。メモには直列・並列回路との対応づけが多く、既習の知識と結びつけて理解している。
- **オーバーフロー**：8ビットで255+1（72%）は計算を伴う問題の中では高め。

### ウィークポイント（つまずき）

- **2の補数・ビット計算**（誤答内訳より）
  - −3（Q2：55%）・−5（Q14：45%）：誤答は 1100（20%）、1010（23%）、1001（16%）などに分散。**「反転」だけで止まる、または「+1」を忘れる**混乱が混在している可能性がある。
  - 4ビット加算（3+4：53%、6+5：40%）：誤答が複数の選択肢に分散（6+5 は 18%ずつ3択）。**根拠のない推測が多い**と読める。繰り上がりの手順が身についていない。
  - 7−2（Q13：35%）：設問が要約のため断定できないが、最終結果（0101）を選んだ生徒が26%。図の途中の手順を問われているのに最終答えを選んでいる可能性があり、**設問の読み取りの問題**も疑われる。
- **真理値表から回路を読み取る・組み立てる**
  - XOR の真理値表の識別（Q3：39%）：誤答は OR（30%）が最多。**「両方1のとき」の扱いで OR と XOR を取り違える**。言葉では OR/XOR の違いを説明できる（記述サンプル）のに、表では見分けられない。
  - NOR（OR+NOT）の識別（Q13：30%）、NOT A AND B（Q15：33%）：誤答が分散しており、2段の組み合わせを順に追う力が弱い。
  - 真理値表の入力順（Q9：44%）：メモに「00→01→10→11の順」と書いた生徒がいる一方で、並べ替え問題の正答は半数未満。
  - 半加算回路：構成（Q7：51%）は XOR+AND が正答で半数。1+1 の出力（Q8：43%）は、誤答が 和=1・桁上がり=0（24%）、和=1・桁上がり=1（23%）に割れている。
- **誤差の概念**：桁落ち（52%）・情報落ち（57%）の取り違えは、桁落ち問題の誤答の23%が「上限を超える」、情報落ち問題の誤答の18%が「上限を超える現象」と、**オーバーフローとの混同**が見える。
- **否定形・「誤っているもの」を選ぶ問題**：1302 Q6（「適切でないもの」46%）、Q7（「誤っているもの」48%）。Q7 は Microsoft Word を選ぶ正答が48%で、Linux（26%）を OS でないと考えた生徒が多い。**内容の弱点というより設問形式（否定形）で正答率が下がっている可能性**がある。
- **スペックの読み取り・応用**：RAM 8GB が何に相当するか（61%）、映像・音声のインターフェース（62%）、並列処理で強化する要素（コア数：58%、クロック周波数・RAM を選んだ生徒が計37%）。**用語は言えても、用途と結びつけた判断が弱い**。
- **用語の定着**：メモに「2の補助数」「浮遊小数点」「活動小数点数」「倫理回路」（論理回路）などの誤記が複数見られる。理解の不足というより用語の表記が定着していない可能性。

### 興味関心

- メモは動画・スライドの要点整理が中心で、**同一の表現が多い**（スライドの転記に近い）。生徒の関心の強さを読み取れる材料は少ない。
- 関心の表れとして読めるもの：GPU と CPU の違い（複数名が記載）、NAND が「万能回路」であること（複数名）、デバイスドライバーの具体例（プリンタなど）、組み込みシステムの記載、直列・並列回路との対応づけ。
- 第1時のスペック調べ（自分のスマホ）は関心を引き出す活動のはずだが、メモには結果が表れていない。ワークシートを確認して、関心の様子を補う必要がある。
- 第4時には「0.1+0.2」のような身近な誤差例への言及がなく、**誤差を日常の場面（電卓・表計算・お金の計算）に結びつける導入**が弱い。

### 次回の単元に向けた改善案・実施上の注意点

1. **補数・加算は1コマで扱いきれない**。次年度は第4時を「補数・2進数の加算（引き算）」と「小数・誤差」に分けるか、第5時の単元テスト前に**補数・加算の演習時間を定位置で確保する**。今年度は第5時導入5分で手順を示すだけなので、テスト前の復習時間は足りない。
2. **補数は手順を分解して板書し、「反転→+1→確認（元の数と足して0になるか）」の検算を毎回行う**。4ビット加算は「繰り上がりを書き込む」形式の練習を増やす。
3. **半加算回路は、XOR＝和・AND＝桁上がりの対応を、第3時の導入で扱った 1+1=10 と明示的に結びつける**。真理値表の「和」「桁上がり」の列を色分けする。
4. **OR と XOR の違いを「両方1のとき」の行に絞って真理値表で比較する活動**を入れる。記述では説明できるので、表を見て回路を特定する練習へつなげる。
5. **誤差5種は混同を防ぐ整理表**（原因・起きる場面・具体例）を用意し、特に桁落ち・情報落ち・オーバーフローを対比する。「0.1+0.2」を導入に使い、**なぜ割り切れないか**を10進数の1/3と対比して説明すると、記述の質が上がる。
6. **否定形の設問は、問題文の「適切でない／誤っている」に下線を引く**習慣を指導する。
7. **第5時の単元テストの結果を確認**し、補数・論理回路の組み合わせ・誤差の混同が単元テストでも残っているかを見る。残っている場合は、次単元（プログラミング）の冒頭で短い復習を行うか、以降の単元で繰り返し扱う。
8. 進数変換は前単元より優先度が下がるが、**補数・加算でつまずいた生徒は変換も怪しい**可能性があるため、次年度も補数の前に確認ドリルを維持する。

## 扱った内容の妥当性（次年度に向けて）

- **全体評価**：ハードウェア → ソフトウェア → 論理回路 → 内部表現という流れは、「コンピュータの仕組みを下から上に学ぶ」順として妥当。第1・2時の概念系は高定着で、この構成と動画視聴＋ワークシートの形式は機能している。
- **修正した方がよい部分**：
  - 第3時：動画20分に AND・OR・NOT・XOR・組み合わせ回路・半加算回路を入れると情報量が多い。半加算回路は「導入の1+1=10 → XOR・AND → 和・桁上がり」と一本の流れで見せ、組み合わせ回路の例（AND・AND+OR・XOR）は絞る。
  - 第4時：補数、固定小数点、浮動小数点、誤差5種（丸め・桁落ち・情報落ち・オーバーフロー・アンダーフロー）は1コマに多い。**固定小数点は浮動小数点の導入として短く触れる程度にし**、誤差は「丸め誤差・桁落ち・情報落ち」を中心にして、オーバーフロー・アンダーフローは補足にする案がある。
  - 単元の目標文に「データの表現方法（2進数・文字コード・画像・音声）」とあるが、文字コード・画像・音声は前単元（02）で扱っており、本単元には含まれない。**目標文を実際の内容（整数・負の数・小数の表現）に合わせる**。
- **追加した方がよい内容**：
  - 第4時または第5時に、**補数・加算の演習時間**（次年度は第4時を2コマに分けるか、第5時冒頭を演習に当てる）。
  - 第4時の導入に「0.1+0.2」など身近な誤差例。
  - 第5時に**返却・解説**（単元計画の備考にはあるが、展開に時間が確保されていない）。
- **削除候補**：明確に不要な内容はない。ただしアンダーフローは扱いが薄く（68%）、誤差の混同を減らすためにも、扱うなら補足と位置づけるのが妥当。固定小数点も同様に重み付けを下げてよい。

## 小テストの妥当性（次年度に向けて）

- **難易度**：1301・1302 は概念問題（80〜93%）から応用問題（46〜67%）まで幅があり、識別力がある。1303・1304 は全体に難度が高く、**1304 は選択式・並び替え13問中9問が60%以下**で、計算が中心。補数・加算は難しい設問と、基礎として全員に解けてほしい設問の区別がつきにくい。1303 は Q13・Q15 が30%台で、組み合わせ回路の発展問題が基礎問題と並んで出題されている。回答数は組あたり約20〜30名のため、組間比較は参考程度にとどめる。
- **機能している設問／見直したい設問**：
  - 機能している：誤答の選び方が診断に役立つ設問。1304 Q5/Q6（桁落ち・情報落ちとオーバーフローの混同）、1303 Q3（XOR を OR と取り違える）、1301 Q10（コア数と RAM・クロックの混同）。
  - 見直したい：
    - 1302 Q6・Q7 は否定形の問いで、知識以前に設問形式が正答率を下げている可能性がある。「次のうち正しいもの」に変えて、知識の定着を測れるようにする。
    - 1304 Q13（7−2の図）は問題文が長く、最終答えと途中の手順を取り違えやすい可能性がある。何を問うているか（途中の補数か、最終結果か）を明確にする。
    - 1304 Q12（6+5 = 1011）：4ビット符号付きの解釈（−5）と符号なし（11）のどちらを想定しているか誤解を招く可能性がある。符号なしと明記するとよい。
    - 1303 のQ番号に抜け・重複がある（Q12、Q14 がなく、Q15 が2つ）。次年度は番号を振り直す。
- **追加した方がよい問題**：
  - 半加算回路の「和＝XOR、桁上がり＝AND」の対応を直接問う問題。
  - 真理値表を自分で完成させる穴埋め問題（入力順の並べ替えだけでなく、出力欄まで）。
  - 補数を段階ごとに分けて問う問題（反転 → +1 → 検算）。
  - 「0.1+0.2」の記述問題の評価基準（「2進数で割り切れない」＋「有限ビットで近似」）を明示する。
- **削除・見直し候補**：1301 Q1（93%）は確認用としては妥当だが識別力は低い。単元テストで出題するなら、より応用的な問いに置き換えてもよい。他に削除すべき設問は見当たらない。
