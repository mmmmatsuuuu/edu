# 第13時（特別授業）：モデル化とシミュレーション

## 本時の目標

「40人で一斉にじゃんけんをしたら、勝負がつくまで何分かかるか？」という問いを、実演とPythonによるシミュレーションで調べる活動を通して、モデル化とシミュレーションの意義（実際には試せないことを試せる・条件を変えて何度でも試せる）を実感する。

> 年間計画の単元07「モデル化とシミュレーション」（4時間）は授業時数の都合で実施せず、その内容を本単元の特別授業1時間に圧縮して扱う。

## 本時のルール（勝負がつく条件）

- 全員で一斉にじゃんけんをする
- 出た手が**2種類だけ**（例：グーとチョキだけ）になったら「勝負がついた」とする
- 3種類すべてが出た／全員が同じ手だった場合は**あいこ**としてやり直す
- 「勝負がつくまでの回数」×「1回あたりの秒数」で、かかる時間を求める

### 教師用：参考値（人数ごとの平均回数）

1回で勝負がつく確率は `3 × (2^n − 2) / 3^n`（n：人数）で、平均回数はその逆数になる。

| 人数 | 平均回数 | 1回5秒の場合 | 1回10秒の場合 |
|---|---|---|---|
| 10 | 約19回 | 約1.6分 | 約3.2分 |
| 12 | 約43回 | 約3.6分 | 約7.2分 |
| 13 | 約65回 | 約5.4分 | 約10.8分 |
| 14 | 約97回 | 約8.1分 | 約16分 |
| 15 | 約146回 | 約12分 | 約24分 |
| 20 | 約1,108回 | 約1.5時間 | 約3時間 |
| **40** | **約369万回** | **約213日** | **約427日** |

- 10分以内に収まる人数の限界：1回5秒なら**14人**、1回10秒なら**12人**
- 10人でもばらつきが大きい（シミュレーションでは中央値13回・最大200回超）。実演では、グループ間で回数に差が出るのが普通である

### モデルの分類と具体例

| 観点 | モデルの種類 | 特徴 | 具体例と、どのようにシミュレーションするか |
|---|---|---|---|
| 表現形式 | 物理モデル | 実物を縮小・拡大したり、形を似せたりして作る立体的なモデル | 自動車や飛行機の模型を風洞に入れて風を当て、空気抵抗を調べる。建築模型に光を当てて日当たりを確かめる |
| 表現形式 | 図的モデル | 対象の構成要素や関係を、図で表したモデル | 路線図をたどって乗り換えや所要時間を比べる。フローチャートを指でたどって手順に誤りがないか確かめる |
| 表現形式 | 数理モデル | 対象の性質や関係を、数式や論理式で表したモデル | 預金の金額を「元金×(1＋利率)^年数」で表し、年数や利率を変えて表計算やプログラムで計算する |
| 時間経過 | 動的モデル | 時間の経過によって状態が変化するモデル | 人口の推移や感染症の広がりを、「1日（1年）進めて計算する」ことを繰り返して予測する |
| 時間経過 | 静的モデル | 時間の経過に関係しないモデル | 売上を「単価×個数」で表し、単価を変えると売上がどう変わるかを比べる。地図で2地点間の距離を求める |
| 偶然性 | 確定的モデル | 偶然の要素を含まず、同じ条件なら必ず同じ結果になるモデル | ボールの落下を数式で計算する。複利計算と同様に、1回計算すれば結果が決まる |
| 偶然性 | 確率的モデル | 偶然の要素を含み、同じ条件でも結果が毎回変わるモデル | サイコロやレジの待ち行列を、乱数を使って何度も試し、平均やばらつきを見る。本時のじゃんけんはこれにあたる |

- 1つのモデルは3つの観点それぞれで分類できる（例：本時のじゃんけんは「数理モデル（プログラムで表現）」かつ「確率的モデル」）。動画では観点ごとに分けて紹介し、最後に本時の題材がどれにあたるかを示す
- 本時の演習でとくに重要なのは確率的モデル（何度も試して平均をとる理由）であるため、確定的モデルとの対比を丁寧に扱う

### 配布コード①：1回だけシミュレーションする（3-3で使用）

```python
import random

n = 10            # じゃんけんする人数（2〜45人）
seconds = 5       # じゃんけん1回にかかる秒数（実演で測った値を入れる）

# 人数の範囲チェック（多すぎるとコンピュータが長時間止まらなくなるため）
if n > 45:
    print("人数は45人までです。45人で実行します")
    n = 45
if n < 2:
    print("人数は2人以上です。2人で実行します")
    n = 2

count = 0
while True:
    count = count + 1
    hands = []
    for i in range(n):
        hands.append(random.choice(["グー", "チョキ", "パー"]))
    if len(set(hands)) == 2:   # 出た手が2種類なら勝負あり
        break
    if count % 1000000 == 0:   # 100万回ごとに途中経過を表示
        print(count, "回目…まだ勝負がつきません")

minutes = count * seconds / 60
print(n, "人で", count, "回目に勝負がつきました")
print("かかった時間：約", round(minutes, 1), "分")
if minutes >= 60 * 24:         # 1日以上かかったときは日数も表示
    print("（日に直すと約", round(minutes / 60 / 24, 1), "日）")
```

- 40人も時間の上限を設けずに最後まで実行させる。「実際にやれば半年以上かかることが、プログラムなら数分で終わる」ことを、待ち時間を含めて体感させるのがねらいである
- 人数は**45人まで**に制限している（それより大きい数を入れると45人に置き換えて実行する）。ふざけて大きな人数を入れ、コンピュータが長時間止まらなくなるのを防ぐためである。1人以下を入れた場合も、勝負がつかず止まらなくなるため2人に置き換える
- 実行時間の目安：40人の平均（約369万回）で、一般的なPCで約30秒、Google Colab では1〜2分程度。回数は試行ごとに大きくばらつき、平均の2〜3倍（Colabで数分）かかることも1割程度ある。なお45人の平均は約2,800万回（1回5秒で約1,620日）で、Colabでは10分前後かかる見込みのため、40人以外は基本的に試させない
- 100万回ごとに途中経過が表示されるので、止まっているわけではないことが分かる。待っている間に「この回数を人間がやったら何日か」を計算させてもよい
- 結果は「分」で表示する（本時の問いが「何分かかるか」のため）。1日以上かかったときだけ、補助として日数も表示する
- 5分程度たっても終わらない生徒は実行を止めさせ（Colabの停止ボタン）、そこまでの途中経過と、終わった生徒の結果を共有する

### 配布コード②：何回も試して平均をとる（3-4で使用）

```python
import random

n = 10            # じゃんけんする人数（2〜20人。ここを変えて調べる）
seconds = 5       # じゃんけん1回にかかる秒数（実演で測った値を入れる）
trials = 100      # 試行回数（1〜1000回。何回シミュレーションして平均をとるか）

# 範囲チェック（大きすぎるとコンピュータが長時間止まらなくなるため）
if n > 20:
    print("人数は20人までです。20人で実行します")
    n = 20
if n < 2:
    print("人数は2人以上です。2人で実行します")
    n = 2
if trials > 1000:
    print("試行回数は1000回までです。1000回で実行します")
    trials = 1000
if trials < 1:
    trials = 1

total = 0
for t in range(trials):
    count = 0
    while True:
        count = count + 1
        hands = []
        for i in range(n):
            hands.append(random.choice(["グー", "チョキ", "パー"]))
        if len(set(hands)) == 2:
            break
    total = total + count

average = total / trials
print(n, "人の平均回数：", round(average, 1), "回")
print("平均時間：約", round(average * seconds / 60, 1), "分")
```

- 平均をとるために何度も繰り返すので、人数は**20人まで**、試行回数は**1000回まで**に制限している（上限いっぱいの20人×1000回でも数秒〜十数秒で終わる）。3-4で調べる人数の目安は10〜16人程度
