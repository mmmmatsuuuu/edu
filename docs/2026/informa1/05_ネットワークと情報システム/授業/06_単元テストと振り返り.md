# 第6時：単元テストと振り返り

## 本時の目標

単元「ネットワークと情報システム」の学習内容を確認し、テストに取り組む。完成した単元マップを使って技術どうしのつながりを振り返り、理解が不十分な点を自覚して次の学習につなげる。

## キーワード

| 用語 | 説明 |
|---|---|
| プロトコル | 通信を行うための約束ごと（手順や形式の取り決め） |
| パケット交換方式 | データを小さく分けて送り、回線を共有する通信方式 |
| IPアドレスとDNS | IPアドレスは機器を識別する番号。DNSはドメイン名とIPアドレスを対応させる仕組み |
| 公開鍵暗号方式 | 公開鍵で暗号化し、受信者だけが持つ秘密鍵で復号する方式 |
| 情報システム | コンピュータとネットワークを組み合わせて、情報の収集・処理・提供を行う仕組み |

## 準備物・教材

- 単元テスト（知識・技能および思考・判断・表現を問う問題）
- 振り返りシート
- 生徒の単元マップ（第1〜5時で書き足したもの）

## 授業展開

| 時間 | 段階 | 学習活動 | 指導上の留意点 |
|---|---|---|---|
| 5分 | 導入 | 完成した単元マップを見ながら、表面でスマホからサーバまでのどこでどの技術が働いているかを、裏面でそれぞれの技術がどんな問題を解決するために生まれたか（何を分けて任せたか）を、各自で確認する。あわせて、IPアドレスのビット数と転送時間の計算手順を1問ずつ板書で示す | 詳細な解説はせず、自分で確認させる。計算は前々単元で弱かった内容のため、手順だけをもう一度示す |
| 35分 | 展開 | 単元テストを実施する。出題の例：ネットワーク機器の役割、パケット交換方式が解決した問題、Webページが表示されるまでの手順（図を使う）、IPアドレスの数・転送時間の計算、暗号化の「問題→解決」の連鎖、情報システムの事例について登場前の問題と解決を説明する記述、否定形の設問 | 不正行為防止に留意。時間が余った生徒は見直しをするよう指示する |
| 10分 | まとめ | 振り返りシートに記入する（①単元マップを使って説明できるようになったこと ②まだつながりが分からない技術 ③身の回りで「この技術が使われている」と気づいたこと）。次単元（データベースとデータの活用）を、POSシステムで集めたデータの話から予告する | 振り返りシートは教師が回収し、次単元の導入や指導に活用する |

## 板書・スライド構成

1. 本時の流れ（単元マップで確認→テスト→振り返り）
2. 単元マップの全体図（スマホ → アクセスポイント → ルータ → インターネット → サーバ → 情報システム）
3. 計算の手順（2ⁿ通り／×8 → ÷通信速度）
4. 振り返りシートの記入観点
5. 次単元の予告：集めたデータをどう管理し、どう活用するか

## 本時の評価

| 観点 | 評価方法 | 内容 |
|---|---|---|
| 知識・技能 | 単元テスト | ネットワークの構成・インターネットの仕組み・Webとメール・暗号化と認証・情報システムの信頼性について正確に説明でき、IPアドレスの数や転送時間を求められている |
| 思考・判断・表現 | 単元テスト | 各技術が解決した問題と技術どうしのつながりを説明でき、情報システムの事例を登場前の問題と解決の仕組みから説明できている |
| 主体的に学習に取り組む態度 | 振り返りシート | 単元マップをもとに理解の定着状況を自己評価し、身の回りの技術と結びつけて記述できている |

## 備考・メモ

- 手順を問う設問（Webページが表示されるまでの順序など）は、単元マップと同じ形の図を使って出題する。
- 否定形の設問は、前単元までと同じく継続して出題する。可能であれば同じ内容を肯定形でも問い、形式の影響と内容の理解を切り分ける。
